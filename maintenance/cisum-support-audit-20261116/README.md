测试环境 18:33 的“如何抢票”请求（会话 3e29a88a-47de-493f-b71f-b85d900dfab4）调用 Qdrant 两次：

同步实现 extensions/qdrant-kb/api.ts 将项目中的 Markdown 统一按 syncAudience 上传，并设置 published；它不会因为文件名包含“内部讨论稿”或正文包含“机密文件”就自动排除。单纯在文档头写注意事项也不是检索层强制隔离，切片可能不带文首。因此本次同时清理内容、移出明确内部材料，并修改客服回答规则。

- 抢票：rush_page.dart 的登录、资格、资产余额、确认、结果查询、查看票券及购票分支；rush_payment_sheet.dart 的授权；app_zh.arb 的“试试手气”“查询结果”“查看门票”等实际标签。
- 反馈：support_widgets.dart，邮箱校验、描述1–500字、最多3张图片、“我的反馈”和新反馈入口。
- 登录/密码：auth_password_policy.dart，8–20位、至少一个英文字母、不含空白；账号历史与退出语义沿用新版指引，不收集用户密码。
- 用户资料：user_profile_edit_page.dart，昵称1–50、简介最多1500；community_profile_dialog.dart，社群名片昵称20，不能混用。
- 入会/关注：artist_club_actions.dart，入会与关注独立，退会不自动取消关注。
- 导航：home_page.dart、profile_page.dart、导航/路由定义的页面入口；路由不进入用户文档。
- 语言：app_locale.dart，七种地区语言，系统中文匹配繁中，未匹配回退英文。
- 浏览器限制：H5Capabilities，群聊、直播、扫码、通知、资产特定操作、导出、生物识别引导 App。

## 回答规则改动

OpenClaw 的 SupportAgent 源提示词增加 Customer-Facing Product Guidance，放在前部，减少长提示词尾部被截断时规则丢失的风险：

- 使用页面名称、按钮和操作步骤，不输出内部路由、接口、代码路径、数据库字段、仓库/分支/服务器/提交等信息。
- 保留确有用途的公开用户网址和错误码；不能由内部路由拼接网址。
- 操作问题使用现行产品指南，不能由白皮书、计划、历史公告补出当前能力或金额。
- published/official 元数据不等于内容是现行操作规则；内部/机密资料不用于用户回答。
- 规则覆盖全部回复语言；旧聊天记录不能充当当前功能证据。

这属于提示词约束，不是输出端硬过滤；不能仅凭源文件修改宣称线上不会再出现问题。
