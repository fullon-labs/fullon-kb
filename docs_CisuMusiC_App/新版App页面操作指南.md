# CisuMusiC 新版 App 頁面操作指南

適用：新版 CisuMusiC App。內容核對日期：2026-11-23。

## 使用範圍

本頁說明新版 App 的頁面名稱與操作入口。找不到相同入口時，請確認使用的是 App 還是瀏覽器版本、Android 還是 iOS，以及 App 版本。功能可用性亦受帳號資格、裝置權限和當前服務狀態影響；不能僅憑此指南認定所有舊版本已提供新增功能。

## 首頁、空間、商城、我的

新版底部四個主要入口為「首頁」「空間」「商城」「我的」。AI 入口可打開客服頁。舊版「票務」「賺分」不再是新版底部標籤。

| 目的 | 用戶操作入口 |
| --- | --- |
| 回到首頁 | 底部「首頁」 |
| 選擇藝人／樂迷俱樂部 | 底部「空間」，選擇藝人；或首頁藝人卡片 |
| 看商城 | 底部「商城」 |
| 看個人中心 | 底部「我的」 |
| 找 AI 客服 | 導航區 AI 入口 |
| 查看反饋／提交新反饋 | AI 客服右上角「我的反饋」，再發起新反饋 |

## Vlog、作品與演出

| 目的 | 用戶操作入口 |
| --- | --- |
| 看 Vlog 列表 | 首頁 Vlog 區全部入口 |
| 看某位藝人的全部 Vlog | 該藝人空間 Vlog 區全部入口 |
| 看單支 Vlog | 點擊 Vlog 卡片 |
| 看某藝人的作品 | 該藝人空間作品區全部入口 |
| 看活動列表 | 首頁演出區全部入口 |
| 看某藝人的活動 | 該藝人空間演出區全部入口 |
| 看活動詳情 | 點擊演出卡片 |
| 參與搶票 | 首頁搶票入口 |

例如查看 IVAN 的全部 Vlog：打開 IVAN 的藝人空間，選擇 Vlog 區的全部入口。藝人空間首頁、全部 Vlog 列表和單支影片詳情是不同頁面。

## 加入與退出俱樂部

在藝人空間點擊加入俱樂部，按登入及入會提示完成。退出時在藝人空間更多選單選擇退出並確認。

加入成功後另行嘗試關注藝人；關注失敗不代表入會失敗。退出俱樂部不會自動取消關注；關注與入會是兩種獨立狀態。俱樂部顯示的權益、群聊及內容資格以當前帳號狀態和頁面規則為準。

## 任務、訂單、票券與資產

| 目的 | 用戶操作入口 |
| --- | --- |
| 做任務賺 CISUM | 首頁「賺更多 CISUM」；藝人空間任務入口 |
| 邀請好友與查看邀請記錄 | 「我的」邀請入口 |
| 查看訂單 | 「我的」→「訂單」 |
| 查看票券 | 「我的」→「票券」 |
| 查看勳章 | 「我的」→「勳章」 |
| 查看資產 | 「我的」→「資產」 |
| 查看代幣交易記錄 | 資產頁更多選單的交易記錄，或選擇資產 |
| 轉帳／收款 | 資產頁更多選單 |

任務獎勵、抽獎消耗、票價和會員優惠以具體頁面顯示為準。

## 個人資料、登入與設置

| 目的 | 用戶操作入口 |
| --- | --- |
| 查看自己的主頁 | 「我的」點擊自己的頭像 |
| 編輯主頁頭像／暱稱／簡介 | 個人主頁更多選單「編輯主頁」 |
| 完善真實姓名等基本資料 | 任務中的完善資料流程 |
| 登入／註冊 | 未登入時打開登入頁 |
| 忘記密碼 | 目前密碼驗證頁的「忘記密碼」，按原登入方式驗證身分 |
| 打開設置 | 「我的」→「設置」 |
| 修改密碼 | 已設定密碼且狀態可用時，設置→修改密碼 |
| 切換語言 | 設置→語言 |
| 導出 | 設置→導出 |

編輯主頁的暱稱限 1–50 字，簡介最多 1500 字；任務中的社群名片對話框暱稱限制為 20 字。基本資料與社群名片、編輯主頁應分開說明。

登入歷史只記錄原生 App 成功登入的手機號和區號，可選擇或刪除本機歷史；不是免密登入，也不是註銷帳號。修改密碼成功後需要重新登入。

## 新版反饋表單

進入 AI 客服，點擊右上角「我的反饋」，再選擇新反饋。登入後填寫有效郵箱及 1–500 字問題描述，可加最多 3 張圖片。表單不要求獨立問題標題。請提供版本、操作步驟、發生時間和錯誤截圖，不提供密碼、驗證碼或私鑰。

## App 與 H5 的邊界

上述以原生 App 為主。瀏覽器版本中的群聊、直播、掃碼、通知、資產轉帳、收款、簽名、交易記錄、帳戶導出和生物識別等功能可能提示使用 App；遇到該提示時，請前往 App 繼續。

## 藝人世界、貼文與評論翻譯

藝人空間中的藝人介紹，以及提供翻譯入口的貼文和評論，可顯示譯文並切回原文。Vlog 評論也支援自動翻譯與原文切換；這不表示影片音訊、字幕或每個內容區塊都會自動翻譯。翻譯未完成時可查看原文，依頁面入口重試。

## 群聊拍照與短影片

在具備群聊資格的 App 帳號中，打開群聊的附件／拍攝入口，可拍照或錄製最長 15 秒短影片，預覽確認後發送。錄影需相機與麥克風權限；權限被拒時按裝置設定處理。此說明適用於已提供拍攝入口的新版本，不代表所有俱樂部或瀏覽器版本均可使用。

## 登入方式與交易密碼

新版支援手機號與 Google 登入，iOS 另有 Apple 入口；Android 原生登入頁目前不顯示 Apple。驗證碼登入、第三方授權與交易密碼驗證不是同一步；需要設定或恢復交易密碼時依畫面繼續。詳細流程見「註冊、登入與帳號恢復」。

## 退出登入

「我的」→「設置」→「退出登入」並確認。支援退出回首頁的新版本會回到首頁，以未登入狀態瀏覽；較早版本可能仍進入登入頁。退出失敗按錯誤提示重試。一般退出登入、修改密碼後重新登入和註銷帳號不能混為一談。
