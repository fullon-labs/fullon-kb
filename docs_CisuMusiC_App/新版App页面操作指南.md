# CisuMusiC 新版 App 頁面操作指南

適用：cisum-app-new 新版 App，cisum-hk-tc 測試環境；核對日期 2026-11-06，代碼版本 6803135ef5ee13e6aa5f24a73bb84e4a28c61a85。

## 使用範圍

本頁是新版 App 的頁面名稱與操作入口說明。使用者看不到相同入口時，先確認 App/H5 與版本，不以舊版截圖推定操作錯誤。下面的 `/...` 是客戶端內部路由核對表，不是完整網址；客服回答優先給頁面名稱和操作步驟，不拼接未驗證的域名或承諾聊天中的路由文字可以點擊直達。

## 首頁、空間、商城、我的

新版底部四個主要入口為「首頁」「空間」「商城」「我的」。AI 入口可打開客服頁。舊版「票務」「賺分」不再是新版底部標籤。

| 目的 | 用戶操作入口 | 新版內部路由 |
| --- | --- | --- |
| 回到首頁 | 底部「首頁」 | `/home` |
| 選擇藝人／樂迷俱樂部 | 底部「空間」，選擇藝人；或首頁藝人卡片 | `/space` → `/space/artist/:artistId` |
| 看商城 | 底部「商城」 | `/mall` |
| 看個人中心 | 底部「我的」 | `/me` |
| 找 AI 客服 | 導航區 AI 入口 | `/ai` |
| 查看反饋／提交新反饋 | AI 客服右上角「我的反饋」，再發起新反饋 | `/feedback` 為獨立提交頁；歷史為彈層 |

## Vlog、作品與演出

| 目的 | 用戶操作入口 | 新版內部路由 |
| --- | --- | --- |
| 看 Vlog 列表 | 首頁 Vlog 區全部入口 | `/vlogs` |
| 看某位藝人的全部 Vlog | 該藝人空間 Vlog 區全部入口 | `/vlogs?artist=藝人帳號` |
| 看單支 Vlog | 點擊 Vlog 卡片 | `/vlogs/:vlogId` |
| 看某藝人的作品 | 該藝人空間作品區全部入口 | `/releases/artist/:artistId` |
| 看活動列表 | 首頁演出區全部入口 | `/events` |
| 看某藝人的活動 | 該藝人空間演出區全部入口 | `/events?artist=藝人帳號` |
| 看活動詳情 | 點擊演出卡片 | `/events/:eventId` |
| 參與搶票 | 首頁搶票入口 | `/activity/rush` |

IVAN 全部 Vlog 範例：`/vlogs?artist=cvvuswqorks1`。藝人空間 `/space/artist/cvvuswqorks1` 與全部 Vlog 是不同目的頁；單支 Vlog 詳情也不是全部列表。舊連結 `/spaceInfo/...?...` 或 `https://space.cisumverse.com/@...` 不應直接當作新版全部 Vlog 的入口答案。

## 加入與退出俱樂部

在藝人空間點擊加入俱樂部，按登入及入會提示完成。退出時在藝人空間更多選單選擇退出並確認。

加入成功後另行嘗試關注藝人；關注失敗不代表入會失敗。退出俱樂部不會自動取消關注；關注與入會是兩種獨立狀態。俱樂部顯示的權益、群聊及內容資格以當前帳號狀態和頁面規則為準。

## 個人資料、登入與設置

| 目的 | 用戶操作入口 | 新版內部路由 |
| --- | --- | --- |
| 查看自己的主頁 | 「我的」點擊自己的頭像 | `/users/:userId` |
| 編輯主頁頭像／暱稱／簡介 | 個人主頁更多選單「編輯主頁」 | `/users/me/edit` |
| 完善真實姓名等基本資料 | 任務中的完善資料流程 | `/account/personal-profile` |
| 登入／註冊 | 未登入時打開登入頁 | `/login` |
| 忘記密碼 | 登入頁「忘記密碼」 | `/forgot` |
| 打開設置 | 「我的」→「設置」 | `/settings` |
| 修改密碼 | 設置→修改密碼 | `/reset-password` |
| 切換語言 | 設置→語言 | `/settings/language` |
| 導出 | 設置→導出 | `/settings/export` |

編輯主頁的暱稱限 1–50 字，簡介最多 1500 字；任務中的社群名片對話框暱稱限制為 20 字。基本資料與社群名片、編輯主頁應分開說明。

登入歷史只記錄原生 App 成功登入的手機號和區號，可選擇或刪除本機歷史；不是免密登入，也不是註銷帳號。修改密碼成功後需要重新登入。

## 新版反饋表單

登入後填寫有效郵箱及 1–500 字問題描述，可加最多 3 張圖片。獨立提交頁為 `/feedback`；AI 客服右上角「我的反饋」打開歷史，可由此新建反饋。表單不要求獨立問題標題。請提供版本、操作步驟、發生時間和錯誤截圖，不提供密碼、驗證碼或私鑰。

## App 與 H5 的邊界

上述以原生 App 為主。當前 `cv-app-h5-new` 對群聊、直播、掃碼、通知、資產轉帳／收款／簽名／交易記錄、帳戶導出、生物識別等入口設置了使用 App 的引導。H5 出現該提示時應按提示前往 App，不能說在瀏覽器中一定可以完成。

本次只更新知識文檔，不修改客戶端路由或 AI 訊息的連結解析；不代表舊版 App 已支援新版入口，也不代表生產環境已發布本次改造。
