# Cisum

CISUM:用代币经济学赋能全球音乐产业

## 一、时代背景

近年来,全球已进入Web3时代。加密货币作为创新交易工具,获得世界各国政府的逐步认可 和政策支持。加密钱包注册量呈几何级增长,加密货币越来越为大众所知晓、熟悉并接受,成 为个人资产的重要组成部分。

然而,加密货币仍面临一些亟待解决的痛点,例如“空气币”泛滥,缺乏核心价值,大多数代币 缺少真实应用场景、生态系统和长期价值。普通人难以在日常生活中使用它们,而“币圈”用户 往往抱持投机心态,缺乏忠诚度,主要专注于短期交易获利。

解决这些问题的关键在于将加密货币与高流量产业生态绑定,增加多样且实用的应用场景,从 而触及大众的日常使用。这将显著提升交易量、频率和用户忠诚度,导致价值稳定且持续增 值。

在各种产业中,音乐产业最适合这一目标,因为其交易特性具有高流量、高频率和高粘性。其 年轻、活跃且忠诚的用户群体与加密货币的目标受众高度契合。音乐产业场景——如版权、 现场演出、周边的销售、排行榜、赛事、艺人粉丝互动以及元宇宙娱乐(AI、VR)——均为加密 货币整合的绝佳机会。

因此,打造一款全球音乐产业生态代币势在必行,CISUM应运而生。

## 二、整体概念

CISUM是“MUSIC”倒拼而成,象征颠覆传统音乐产业模式。

CisuMusiC科技公司利用区块链技术,依托其专有的FULLON公链,创建CISUM——一款 锚定全球音乐产业生态的加密货币。这将构建一个由音乐机构、艺人和粉丝共建、共治、共享 的生态系统。在保留现有交易结构和各方利益不变的基础上,通过代币经济学赋能音乐产业, 由此,音乐机构、艺人和粉丝都能获得更大的利益和价值。
