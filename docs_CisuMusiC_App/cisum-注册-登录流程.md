# cisum-注册-登录流程

## 图片说明

注册&登录流程图,泳道包含 APP、后台、合约。

注册流程: 用户输入信息 -> APP 获取短信验证 -> 后台短信验证码服务 -> APP 创建公私钥对 -> APP 提交手机号、验证码、公钥 -> 后台激活账号服务 -> 合约 newaccount -> 后台返回 token -> APP 注册成功。

登录流程: 用户输入手机号 -> APP 获取短信验证 -> 后台短信验证码服务 -> APP 用手机号查询本地钱包。

若本地钱包存在: APP 查询账号公钥 -> 合约根据账号查询公钥 -> APP 校验公钥是否一致。

若公钥一致: APP 重置钱包 -> 后台重置登录 -> 合约 updateauth -> 后台返回 token -> APP 登录成功。

若公钥不一致或本地钱包不存在: APP 创建新的公私钥对 -> APP 提交手机号、短信验证码、公钥 -> 后台重置登录 -> 合约 updateauth -> 后台返回 token -> APP 重置钱包/登录成功。

关键对象: 手机号、短信验证码、公钥、私钥、本地钱包、token、newaccount、updateauth。
