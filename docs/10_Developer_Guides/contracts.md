# 智能合约开发路径

目标：明确从合约设计到部署验证需要完成的工作。

## 官方源码入口

- [FullOn Core](https://github.com/fullon-labs/flon-core)：节点与 RPC 实现。
- 合约编译工具链、安装包及版本兼容矩阵：当前知识库尚未核验，应先向维护者确认。本文不提供未核实的安装命令、编译器参数或部署命令。

## 开发步骤

1. 明确目标网络与节点版本，取得兼容工具链、示例合约和测试账户；记录版本及来源。
2. 设计 actions、参数、表和 scope，区分调用者、授权权限与资源付款者。涉及资产时明确合约、符号、精度和金额边界。
3. 为写操作实现权限与输入校验，审查重复调用、重入或内联调用影响，以及资源消耗边界。
4. 编译生成 WASM 与 ABI，在隔离环境测试授权失败、非法参数、重复操作和边界金额，并核对表状态。
5. 在测试网络部署，使用当前 ABI 构建交易，核验执行结果与不可逆状态。节点内置模拟或只读接口不能替代完整的写入测试。
6. 上线前复核部署账户权限、代码/ABI、版本与升级计划。升级前保存旧 WASM、ABI、代码哈希及关键配置；涉及表结构变化时单独制定迁移方案，不能假设回滚代码即可回滚数据。
7. 部署后用 `get_code_hash`、`get_abi` 和 `get_table_rows` 验证链上结果，记录交易 ID 与版本。
