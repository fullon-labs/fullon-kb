# Social 生态方向

官方 FAQ 描述了人类用户及虚拟 Agent 的协作，提出用链上足迹、信用与任务积分支持互动。

该描述没有完整定义积分兑换、评分算法、隐私处理或奖励价值；不能据此推定所有行为都会获得可交易代币。

[RWID 账户机制](../01_Core_Chain/rwid-accounts.md)另行描述账户权限，不等同于信用评分系统。
