# 新手入门：钱包、账户与网络

目标：确认你使用的网络、账户和钱包，为收发资产做好准备。

## 开始前

- 仓库收录的 [HuFu Wallet](../02_Ecosystems/hufu-wallet.md) 支持 FullOn；从[HuFu 官网](https://hufu.io)查找下载入口。该产品页仍为草稿，本文未重新验证商店版本或界面。
- 钱包是管理密钥和发起签名的工具；账户是链上的身份与权限主体。安装钱包不等于已经拥有可用的链上账户。
- 主网资产与测试网资产分开；账户名称相同也不代表处在同一条链。

## 操作步骤

1. 从官方入口安装钱包，按当前界面创建或导入账户。若钱包要求账户创建服务，先确认服务支持的网络和费用；本文不承诺免费开户。
2. 按钱包提供的方式备份恢复材料，离线妥善保存。不要向客服、网站或聊天机器人提供私钥、助记词或钱包密码。
3. 在钱包确认所选网络，记录完整账户名和公开收款信息。
4. 打开对应网络的区块浏览器，查询账户是否存在，核对账户名和资产。仓库已有[Flonscan](https://flonscan.io)入口；使用时确认其显示的网络。
5. 先完成一笔[小额收发](transfer-token.md)，并按[交易查询指南](transaction-status.md)检查结果。

## 完成标准

你能在钱包与对应网络的浏览器看到同一账户，并能识别要接收资产的合约、符号和网络。

账户恢复、社交恢复和权限变更取决于账户实际设置；不要仅凭账户类型名称假设一定能恢复。
