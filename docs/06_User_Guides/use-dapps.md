# 使用 DApp：连接、授权与确认

目标：了解应用用途，并在签名前核对实际操作。

## 在 PC 使用 HuFu 扫码连接

DApp 在 PC 网页打开时，可选择其 **Wallet Connect** 入口，使用 **HuFu App 扫描二维码**，选择并确认要连接的 **FullOn 账户**。PC 页面显示正确账户后，再发起应用操作；交易签名仍需在 HuFu 中核对并确认。

完整步骤及连接排错见[HuFu 的 PC 扫码连接说明](hufu-mobile.md)。

## 通用步骤

1. 从项目官方入口进入，确认域名、网络与钱包账户。
2. 连接钱包，区分账户连接请求和实际交易签名。
3. 根据操作核对参数：兑换看输入/输出资产与最少到账量；跨链看来源链、目标链、接收地址与支持资产；锁定看受益人和释放时间。
4. 阅读钱包展示的每个动作和授权权限；界面描述与签名内容不一致时停止操作并向项目方核实。
5. 首次操作先小额测试。保存交易 ID，按[交易查询](transaction-status.md)检查。
6. 跨链操作分别保存来源链交易、应用订单号及目标链交易；来源链成功不等于目标链已到账。

应用未提供的规则不能自行推断。兑换费率、跨链时效、资产赎回与收益条件以当前应用披露为准。
