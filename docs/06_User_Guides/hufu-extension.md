# HuFu Wallet Chrome 扩展：下载与使用

本指南面向电脑端 Chrome 用户。手机端请看[HuFu App 指南](hufu-mobile.md)。安装扩展、创建本地钱包、拥有链上账户和连接 DApp 是不同步骤。

## 官方下载入口

- [HuFu 官网](https://hufu.io)：优先从官网的 Chrome 下载入口进入。
- [Chrome 应用商店内搜索 HuFu Wallet](https://chromewebstore.google.com/search/HuFu%20Wallet)：这是官网当前指向的搜索入口，**不是已核验的固定扩展详情页**。

2026-11-02 核对官网发布资源时，其 Chrome 按钮指向商店搜索。本文尚未核验固定扩展 ID、发布者名称或某一商店版本；如果结果不明确或无法确认与官网关联，请从官网支持渠道确认，不要只凭名称、图标或排名安装。

## 安装与固定图标

1. 在电脑 Chrome 的普通窗口打开官网入口，在商店核对扩展详情中的发布者、网站关联、权限和更新信息。
2. 确认是官方扩展后，选择“添加至 Chrome”，阅读权限提示，再确认“添加扩展程序”。
3. 从 Chrome 工具栏的扩展菜单打开 HuFu；需要时固定图标，便于日后访问。
4. 按扩展当前界面完成初始化。浏览器受组织策略管理时可能无法安装；先核实管理限制。

不要把网站展示的普通下载文件当作 Chrome 商店安装步骤。本文不提供未经核实的 CRX、ZIP 或“加载已解压扩展”安装包。

## 创建或导入钱包与账户

1. 按当前版本支持的方式创建钱包或导入已有账户，仅在确认的官方扩展界面处理恢复材料。
2. 设置扩展提供的本地访问保护，并妥善备份；不要把钱包密码、私钥或恢复短语交给 DApp。
3. 若导入已有账户，核对其公钥/权限、完整账户名与网络；仅导入密钥不会新建链上账户。
4. 若需要新账户，按[开户指南](create-account.md)完成链上创建，再用对应网络浏览器查询账户是否存在。

扩展密码保护本地访问，不等于链上 owner 权限，也不保证账户可恢复。Chrome 登录或浏览器同步不能作为钱包密钥已备份的证明。移除扩展或更换浏览器配置前，先确认恢复方式可用。

## 选择 FullOn 网络并接收资产

在扩展列出的网络中选择应用要求的 FullOn 网络；如果当前版本没有目标网络，先向官方确认支持情况，不要凭猜测填写 RPC 或 Chain ID。主网与测试网不能混用。

核对账户名、资产合约、符号与精度，再复制收款信息。先小额测试；转账和 memo 检查见[收发资产](transfer-token.md)。

## 连接 DApp 与签名

1. 通过项目官方入口打开应用，例如 [DAO Gov](https://daogov.flon.network/) 或 [FullSwap](https://fullswap.flon.network)。
2. 解锁扩展并确认账户、网络。若应用提供“HuFu 浏览器扩展”选项，选择该项；扫码连接手机钱包是另一种连接方式，不要求为了扩展连接而扫码。
3. 在扩展授权窗口核对站点来源和账户后批准连接。安装后已打开的页面可能需要刷新，才能发现扩展。
4. 连接账户不等于批准后续交易。每次签名前检查网络、合约、动作、参数、授权账户、数量及实际收款人。
5. 签名后保留交易 ID，按[交易状态指南](transaction-status.md)确认执行成功与不可逆状态。超时或余额未刷新时先查原交易，不要重复提交。

更换账户或网络后，应让应用重新连接并核对。结束使用时可断开 DApp 会话并锁定扩展；断开连接不会撤销已执行交易或改变链上权限。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 商店搜索不到或出现多个同名结果 | 重新从官网进入，核对发布者与网站关联；无法确认时向官方求证。 |
| 没有扩展图标 | 检查当前 Chrome 配置中的扩展列表和启用状态；固定图标不等于安装扩展。 |
| DApp 没有检测到扩展 | 确认扩展已启用/解锁并允许访问该站点，再刷新；不要直接授予所有网站权限来试错。 |
| 弹窗没有打开 | 查看扩展图标是否有待处理请求，确认当前浏览器配置与站点访问权限；先核对是否已广播。 |
| 连接后显示错误账户/网络 | 在扩展切换后断开并重新连接，核对完整账户名和 Chain ID。 |
| 有 FLON 但治理权为零 | 液态余额与 DAO 内部 POWER 不同，不能仅凭余额判断可投票。 |
