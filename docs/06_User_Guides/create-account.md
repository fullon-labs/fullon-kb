# 如何开通 FullOn 账户

目标：在选择的网络上拥有可查询且可签名的账户。

## 选择开户方式

- **钱包提供的普通账户创建或导入**：适合自行管理密钥的用户；确认 owner 与 active 如何配置。
- **钱包或应用提供的 RWID 开户**：适合使用该产品认证/恢复服务的用户；先阅读[RWID 账户](../01_Core_Chain/rwid-accounts.md)。当前是否开放、认证方式和收费以应用为准。
- **由已有账户创建**：适合团队或开发者代为提交链上开户；用户应自行生成并保管密钥，仅向创建方提供公钥。

## 在手机上开通

1. 按[HuFu 安装指南](hufu-mobile.md)安装官方钱包，选择 FullOn 网络。
2. 在当前应用可用的创建/注册入口选择账户方式；若只看到导入，不要把导入已有密钥误认为新开户。
3. 按界面完成账户名、密钥备份或认证步骤，确认展示的费用及服务条件。
4. 等待链上创建完成，保存账户名和开户交易 ID（若应用提供）。
5. 在对应网络浏览器查询账户，再尝试钱包发起的小额操作。

## 如何判断已激活

“注册应用”“生成钱包”“链上账户已创建”和“有足够 gas 可操作”是不同状态。用浏览器或 `get_account` 确认账户存在；若资源不足，按钱包指引补充。本文没有确认一个适用于所有账户的通用 `activate account` 动作。

无法创建时检查名称占用或命名限制、网络、创建服务状态和费用。不要重复支付同一开户请求。
