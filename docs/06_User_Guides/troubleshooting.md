# 用户常见问题与求助

| 问题 | 先检查 | 下一步 |
| --- | --- | --- |
| 钱包找不到账户或余额 | 网络、完整账户名、资产合约 | 在同网络浏览器交叉查询；不要反复导入密钥到陌生工具 |
| 提示资源或费用不足 | 钱包显示的资源项、可用余额 | 按当前钱包说明处理，不凭旧文档估算固定费用 |
| 签名取消或权限不足 | 当前账户、所需权限、是否取消确认 | 核对权限；不要为通过报错而随意提高授权 |
| 转账查询不到 | 交易 ID、网络、时间、浏览器索引 | 查询原交易并保留证据，确认前不要重复付款 |
| 链上成功但交易所未入账 | memo、币种、最低金额、确认要求 | 向接收平台提交交易 ID 和公开信息 |
| 跨链未到账 | 来源链状态、订单、目标链地址 | 向桥官方支持核查订单，勿直接重复跨链 |

## 求助时提供

- 所用钱包或应用名称、版本、网络。
- 公开账户名、交易 ID、发生时间与时区。
- 操作步骤、预期结果、实际错误信息或已脱敏截图。
- 跨链问题附来源链、目标链和订单号。

不要提交私钥、助记词、密码、验证码或带访问凭据的链接。仓库目前没有已核验的统一客服入口，请从相关钱包或项目官网查找支持渠道。
