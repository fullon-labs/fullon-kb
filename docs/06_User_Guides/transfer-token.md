# 收发资产：第一次转账

目标：在正确网络收发指定资产，并确认结果。

## 接收资产

1. 在钱包选择网络和资产，复制完整收款账户或钱包提供的收款信息。
2. 告知付款方网络、账户、资产及必要备注。交易所或托管服务可能要求 memo；以接收方充值页面为准。
3. 首次使用先小额测试，在正确网络的浏览器核对结果，再进行后续操作。

## 发送资产

1. 核对网络、收款账户、代币合约和符号。同名符号不保证是同一资产。
2. 输入数量和接收方要求的 memo；不要仅凭剪贴板内容判断地址正确。
3. 在签名确认页再次核对收款方、数量、合约、动作、授权账户及钱包展示的资源或费用信息。费用不足时，按当前钱包提示处理；本文不提供固定费率。
4. 确认无误后签名，保存交易 ID。不要连续重复点击发送。
5. 按[交易查询](transaction-status.md)核对执行结果、收款账户余额变化和不可逆状态。

## 完成标准

交易执行成功、包含的转账数据正确，且所在区块达到不可逆状态。若接收方为交易所，还需等待其自己的入账处理。

转账报错或未到账时，先查原交易再决定是否重试，详见[排错指南](troubleshooting.md)。
