# 如何通过 FullSwap 交易代币

FullSwap 是仓库收录的 AMM 兑换应用。目标是把一种资产兑换为另一种资产，并核对实际到账。

## 操作前准备

准备目标网络的钱包账户、要卖出的资产及操作所需资源。从[官方入口](https://fullswap.flon.network)进入；当前支持的网络、交易对、费率和界面以应用显示为准。

## 兑换步骤

1. 连接钱包，核对网络和当前账户。
2. 选择卖出与买入代币。核对完整合约和符号，不能仅凭名称或图标识别资产。
3. 输入卖出数量，查看报价、兑换路径、费用、价格影响和最少到账量（若当前界面提供）。
4. 了解滑点：实际成交价格可能在报价后变化；提高容忍度会降低最低可接受结果，不应为了消除错误而盲目提高。
5. 在钱包检查签名的资产、转出数量、接收合约及动作。FullSwap 实现可以通过代币 `transfer` 通知和 memo 触发兑换，不能仅凭动作叫 `transfer` 就判定是普通收款。
6. 签名并保存交易 ID，按[交易查询](transaction-status.md)确认成功执行与不可逆状态。
7. 核对买入代币余额；链上可能包含多条内联动作，以完整交易和余额变化为准。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 找不到代币或交易对 | 确认网络、合约及是否存在受支持市场；不要选同名替代资产 |
| 报价变化或滑点失败 | 重新获取报价，评估数量和价格影响后再签名 |
| 流动性不足 | 评估交易规模，不以显示报价保证可成交 |
| 已提交但余额未更新 | 查原交易和代币合约；确认前不要重复兑换 |
| 不理解 memo 或合约 | 停止签名，向官方支持核实 |

发行代币并不自动获得 FullSwap 上架或流动性；开发者见[发行代币](../10_Developer_Guides/issue-tokens.md)。
