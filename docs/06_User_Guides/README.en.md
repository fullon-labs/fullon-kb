# User guides

Start with the task you want to complete; no node or RPC knowledge is required.

1. [Getting started](getting-started.md): wallets, accounts, and networks.
2. [Create an account](create-account.md): ordinary accounts, RWID, and creation status.
3. [Download and use HuFu](hufu-mobile.md): manage FullOn on a phone.
4. [Transfer assets](transfer-token.md): receiving, sending, and memo fields.
5. [Use DApps](use-dapps.md): connections, authorization, and transaction checks.
6. [Trade tokens on FullSwap](fullswap.md): quotes, slippage, and receipts.
7. [Check transaction status](transaction-status.md): submitted, included, and irreversible.
8. [Troubleshooting and support](troubleshooting.md).

For background, read [FullOn accounts](../01_Core_Chain/accounts.md) and [RWID accounts](../01_Core_Chain/rwid-accounts.md). To write software, use the [developer guides](../10_Developer_Guides/README.md).
